# oxdroid.github.io

Official landing and marketing website for **oxdroid** — mobile security for what's next.

## Tech Stack
- **Framework:** Next.js (App Router, Static Export)
- **Styling:** Tailwind CSS & Custom CSS
- **Deployment:** GitHub Pages via GitHub Actions

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
